# Newsletter Context

Use these facts whenever a newsletter skill needs to choose language, audience, website, or local context.

## RSoW

- Full name: `Řekni si o web`.
- Common abbreviations: `ŘSoW`, `RSoW`, `RSOW`.
- URL: `https://www.reknisioweb.cz/`.
- Language: Czech.
- Context: Czech audience and Czech context, especially for events, examples, news, and references.
- Audience: clients of web designers.

## BBtn

- Full name: `Better Button`.
- Common abbreviation: `BBtn`.
- URL: `https://www.better-button.com/`.
- Language: English.
- Context: global audience with a primary European and Central European context, especially for events, examples, news, and references.
- Positioning: Better Button is written in the heart of Europe, from Prague, and explicitly represents a European view on websites and apps.
- Localisation rule: When a Czech reference is useful, frame it as a European or Central European example unless the Czech specificity is essential.
- Closing signature: End the newsletter with a Prague invitation when it fits the issue voice.
- Audience: clients of web designers.
